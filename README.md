# Emergency Room Backend

This is the backend service for the Emergency Room application. It provides APIs for managing patient records, appointments and emergency rooms.

## Table of Contents

- [Installation](#installation)
- [Usage](#usage)

## Installation

1. Clone the repository:
  ```sh
  git clone https://ariumms@dev.azure.com/ariumms/gestion-sala-de-emergencia/_git/emergency-room-backend
  ```
2. Navigate to the project directory:
  ```sh
  cd consultorio-medico-backend
  ```
3. Install dependencies:
  ```sh
  npm install or pnpm install or yarn
  ```

## Usage

1. Start the development server:
  ```sh
  npm start
  ```
2. The server will be running at `http://localhost:{PORT || 80}`.
